Generic CRUD operations for Intello game sets

This module provides generic helper functions for common CRUD operations that are shared across all game set types (Keywords, Flashcards, etc.).

§Usage

Instead of duplicating validation and logging in each *_ops.rs file, use these generic functions:

ⓘ
use crate::services::intello::crud_ops;

// In keywords_ops.rs:
pub async fn get_user_keyword_sets(&self, user_id: &str) -> Result<Vec<KeywordSet>, IntelloError> {
    crud_ops::get_user_sets(self.keywords_repo.as_ref(), user_id, "keywords").await
}
